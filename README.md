# ログ匿名化ツール

バージョン：v1.0.0
ファイル：`loganonym.html`（単一HTMLファイル）
SHA-256：`98d4b0c0567cf498329453ef0350ce7f878a7bc71833cc7d95342d7e60310161`

## 概要

ログを共有する前に、個人情報や機密情報らしき箇所を置き換えるためのブラウザツールです。ログをページに貼り付けると、匿名化の候補を一覧で提示します。候補ごとに「承認／除外」を人が判断し、承認したものだけを置換します（自動で勝手に書き換えることはしません）。

すべての処理は端末内のブラウザで完結します。外部サーバーへの送信は行いません。ページ自体にも外部リソースの読み込みはなく、Content Security Policy で通信を遮断しています（`connect-src 'none'`）。ダウンロードしたファイルをオフラインで開いても動作します。

## 使い方

1. `loganonym.html` をブラウザで開く（オフライン可）。
2. ログをテキストエリアに貼り付ける（UTF-8、最大1,000,000バイト）。
3. 「検出」を押すと、候補が一覧表示される。
4. 候補ごとに内容と文脈を確認し、「承認」か「除外」を選ぶ。同じ種別・原文の出現箇所はまとめて扱われ、箇所単位の除外もできる。
5. 「承認済みを置換してプレビュー」を押すと、置換結果が表示される。
6. 結果全体を目視で確認してから、「結果をコピー」でコピーして使う。

## 検出対象

- IPv4アドレス、IPv6アドレス
- メールアドレス
- 明示欄（`aws_account_id` など欄名が付いた値）のホスト名、AWSアカウントID

対象外の例：MACアドレス、ARN全体、ユーザー名、認証情報、独自ルールでの検出、複数ファイルの一括処理、置換の復元（可逆モード）。

## 匿名化の限界（重要）

- **完全な匿名化は保証しません。** 検出できるのは上記のパターンに合うものだけです。文脈から個人が推測できる情報、パターンに合わない表記、対象外の種類の情報は残ることがあります。
- 候補の「承認／除外」は人の判断が前提です。未確認の候補は置換されません。
- 共有前に、必ず結果全体を目視で確認し、所属組織のルールに従ってください。

## 動作環境

- モダンブラウザ（Chrome、Edge、Firefox、Safariなど。JavaScriptが動作すること）
- インストール不要、追加の依存なし。単一HTMLファイルを開くだけで動作します。
